SPARK WEAR

心動衣櫥

下載

曾經，我也是個擁有 547 件衣服的「購物狂」。

那時候，打開衣櫃不僅沒能帶給我喜悅，反而是一場焦慮。常常買了一模一樣的單品卻不自知，看著滿坑滿谷的衣服，每天早上卻依然覺得「沒衣服穿」。

直到那時，我讀了《斷捨離》和《怦然心動的人生整理魔法》，那一刻，我決定改變。

「整理，不是為了丟棄，而是為了重啟。」

為了找回與物品的連結，我親手打造了 SPARK WEAR。它不只是一個衣櫃管理工具，更是我冷靜消費的「清單」。透過它，在購物之前，我能隨時翻閱衣櫃，確認哪些單品已經足夠，成功地將衣櫃精簡至 110 件左右。

現在，衣櫃不再是負擔，而是我每日穿搭靈感的來源：
單品履歷：透過拍攝穿搭，紀錄每一件單品的使用率，讓被冷落的舊愛重新發光。
趣味排行：我設計了專屬投票系統，自動產出使用率與 C/P 值排行榜。原來，我最常穿的是那件基礎款針織衫，而不是當初失心瘋買的那件毛毛外套。

在這裡，斷捨離不再痛苦，反而是一場關於「品味」的自我挖掘。
SPARK WEAR，邀你一起，讓衣櫃大減重，讓生活更輕盈。

  • 建立衣物資料庫：輕鬆收納所有單品，讓衣櫃一目了然。
  • 趣味穿搭排行榜：透過數據，看見你最常穿的是哪件，並找出 C/P 值最高的單品與最愛的品牌。
  • 穿搭日記：利用穿搭牆將單品使用狀況視覺化，讓每天的造型更有條理。
  • 精準紀錄：不論是拍攝紀錄或手動投票，都能精確統計使用次數，讓單品不再被冷落。
  • 聰明管理：透過長按或多選功能，即可進行批次重新分類或刪除，讓整理更有效率。
  1. 拍攝並建立衣物資料庫：將衣櫃裡的單品逐一拍攝建檔。
  2. 記錄每日穿搭：出門前拍攝穿搭照，並點選當日使用的單品。
  3. 手動補充紀錄：若當天沒有穿搭照，也能透過手動方式補充單品的使用次數。
  4. 觀賞趣味排行：自動生成的排行榜，讓你透過數據重新認識自己的穿搭風格與單品使用狀況。

SPARK SHAPE

心動曲線

下載

隨著年紀增長，代謝逐漸趨緩，加上生活中上有老下有小，工作壓力接踵而至，體重管理似乎成了這階段最大的挑戰。

為了紀錄努力的痕跡，我一直有拍攝身形紀錄的習慣，但我發現，單純的照片散落在手機相冊裡，很難精確看出變化。如果有一個專屬的工具，能讓我把這些紀錄像日記一樣管理，甚至能直接「並排對比」，那該有多好？

於是，SPARK SHAPE 誕生了。

「看見進步，是堅持下去最好的動力。」

現在，我不再需要憑感覺猜測，只要叫出相簿，過去與現在的對比一覽無遺。這種清晰的軌跡，讓我更有動力去面對生活中的每一項挑戰。

  • 身形紀錄：定期拍攝並建檔，記錄下每一刻的身形變化。
  • 並排對比：透過系統化的對比功能，讓進步一目了然。
  • 精準比較：支援「正面對正面」、「側面對側面」的專業級比對，確保對比基準一致。
  • 局部細節：支援照片拉大、縮小，讓你能精準檢視局部的細微變化。
  • 隱私與安全：專屬的隱私儲存空間，讓你能安心記錄身體的每一個階段。
  1. 拍攝紀錄：點選「新增」，拍攝下當下的身形照。
  2. 輔助對位：使用內建的「對準框」功能，確保每次拍攝的角度與位置一致。
  3. 時間軸管理：儲存後 APP 會自動整理成時間軸，進入「對比」模式即可進行並排比較。
  4. 回顧與激勵：定期瀏覽進化後的對比圖，看見自己的努力，為下一個階段注入滿滿動力。

SPARK SCALE

心動體重

下載

隨著年紀增長，代謝逐漸趨緩，加上生活中大大小小的壓力，體重管理成了這階段的一大難題。

過去，我習慣用 Excel 記錄身體數據，但這畢竟不夠直觀，也很難隨時翻閱。我心想，如果能有一個隨身 App，不只管理數據，還能幫我分析身型、給予穿搭靈感，那該有多好？

於是，SPARK SCALE 誕生了。

「數據，是為了讓我們更了解自己。」

這不僅是數字的堆疊，而是與自己身體的一場對話。現在，我不僅能隨時掌握變化，透過圖表看見趨勢，更棒的是，它還會告訴我適合的身型穿搭與避坑建議。每當看到成長，那種被激勵的感覺，成了我持續堅持的動力。

  • 數據紀錄：輕鬆記錄體重、體脂等關鍵身體數據。
  • 圖表趨勢：數據自動圖表化，一眼掌握長期的身體變化趨勢。
  • 身型智慧分析：透過系統分析你的身型類別，直接獲取量身打造的穿搭建議。
  • 避坑指南：實用的穿搭避坑建議，讓你買對衣服，穿出最完美的比例。
  1. 新增數據：量完數據後開啟 App，點選「新增數據」。
  2. 輸入資訊：輸入今日的身體尺寸與組成，按下儲存。
  3. 趨勢追蹤：系統自動整理成時間軸，進入「報告」查看折線圖分析。
  4. 風格優化：點選分析功能，確認自己的身型分類，參考系統推薦的穿搭法則與避坑建議。

SPARK PLATE

心動餐盤

下載

「明明覺得自己吃得很乖，為什麼體重還是不聽話？」

相信這句話，是許多人在體重管理路上共同的困擾。過去，我也曾興致勃勃地下載各種計算卡路里的 APP，但很快就發現：我不想被冷冰冰的數字追著跑，我只是想知道，我今天到底吃了些什麼？

「餐盤，是一日生活的誠實鏡子。」

為了擺脫數字壓力，我打造了 SPARK PLATE。它不追求精準的卡路里，而是用直觀的「九宮格」排列出你的一日三餐。一眼望過去，吃得好不好、原型食物佔比高不高，全都在畫面上攤開來——那些偶爾的「小放縱」瞬間無所遁形，讓你在下一餐更有意識地做出更好的選擇。

  • 直覺飲食紀錄：拍照即可輕鬆紀錄三餐，讓吃飯這件事回歸單純的快樂。
  • 飲食習慣回顧：透過日誌檢視長期飲食模式，察覺容易被忽略的習慣。
  • 視覺化分享：支援截圖與 3 至 21 宮格組圖輸出，將你的飲食成果一鍵分享給親友，成為彼此的健康啦啦隊。
  1. 隨手紀錄：吃飯前拍攝照片，或從相簿中上傳餐點。
  2. 加入標註：為餐點添加心情備註，並評估等級（標註是否為原型食物），讓紀錄更具參考價值。
  3. 瀏覽九宮格：系統將一日三餐自動排列成清晰的九宮格，讓你一眼看見飲食品質。
  4. 組圖輸出：隨時截圖或選取 1 到 7 天的紀錄，製作成精美的拼貼組圖，分享你的健康生活方式。

SPARK LOG

心動筆記

下載

「巷口那間咖啡廳，到底叫什麼名字？」

你是不是也有過這種經驗——路上偶然發現一間很喜歡的小店，當下想著「下次要再來」，結果過了幾天，連店名都想不起來，更別說地址在哪裡。

我也是這樣，手機裡存了滿滿的照片，但問我「那間店在哪」，永遠講不清楚。直到我決定，把每一次心動的瞬間都好好記下來——SPARK LOG 誕生了。

現在，每次發現喜歡的店家，我都會拍張照、記下地址，並用愛心評分代表喜歡的程度。久而久之，這些紀錄變成了一份屬於自己的口袋名單，想找好吃的、好買的，打開 APP 排行榜，答案一目了然。

  • 快速記錄：拍照即可建檔，記下店名、地址與分類。
  • 心級評分：用 1～5 顆愛心評定喜愛程度，回憶當下的心動感。
  • 分類整理：依服飾店、飲料店、餐廳等類型自動歸類，一目了然。
  • 智慧排行：依心級高低排序，搭配分類篩選，秒速找出口袋名單第一名。
  1. 發現喜歡的店家，點選「+」拍照建檔。
  2. 輸入店名、地址，選擇分類。
  3. 給予 1～5 顆愛心評分，記錄當下的喜愛程度。
  4. 透過「分類」或「排行」回顧整理過的店家清單。

SPARK LIST

心動清單

下載

「這個好想要喔……」滑手機滑到一半，看到喜歡的東西，手就不自覺點下「加入購物車」。

我也是這樣，常常一時衝動下單，東西到貨後才發現，衝動來得快，退得也快——熱情往往撐不過拆箱那一刻。

於是，我打造了 SPARK LIST。這是一份專屬於「生火單品」的口袋清單，不管是衣服、包包、鞋子、電器，甚至是車子、遊戲機，通通可以先記下來，讓自己有個緩衝的空間。

加入清單時，設定一段冷靜期，再勾選幾項理性的購買條件——只有時間到了、條件也滿足，單品才會真正解鎖。等待的過程裡，每一次忍住不買，都會累積一點忍術點數，練成忍術達人；如果最後還是決定入手，也會有一場專屬的「畢業」小慶祝。SPARK LIST，陪你把每一次心動，都留給真正值得的那一件。

  • 生火清單：不限類別，衣服、包包、鞋子、電器、車子、遊戲機都能記錄下來。
  • 冷靜期倒數：自訂天數，讓一時衝動有時間慢慢降溫。
  • 理性條件檢核：內建購買條件，至少勾選 3 項通過理性把關，才有機會解鎖。
  • 忍術點數養成：忍住不買就能累積忍術點數，集滿升級忍術達人；買下則迎來畢業儀式。
  1. 發現生火的單品，拍照或輸入資訊，選擇分類加入清單。
  2. 設定冷靜期天數，並勾選符合的購買條件（至少 3 項）。
  3. 等待期間，隨時可以按下「忍住不買」，累積忍術點數。
  4. 冷靜期倒數歸零且條件滿足後，單品自動從冷靜區跳到解鎖區，跳出恭喜視窗。
  5. 決定入手就按下「已購買」，完成畢業儀式，單品自動從清單移除。
